# Arquitetura / Engenharia de Software

Direção técnica para sistemas sustentáveis.

## Evolução e governança

- [Arquitetura evolutiva com agentes de
  IA](/docs/arquitetura-engenharia/arquitetura-evolutiva-com-agentes-de-ia.html):
  decisões reversíveis, especificações, limites de execução e feedback contínuo
  para mudanças assistidas por IA.
- [Fitness functions
  arquiteturais](/docs/arquitetura-engenharia/fitness-functions-arquiteturais.html):
  como transformar propriedades arquiteturais em sinais, limites, gates e
  evidências repetíveis.

## Fundamentos relacionados

- [Context
  Engineering](/docs/arquitetura-engenharia/context-engineering-fundamentos-para-agentes-de-ia-confiáveis.html):
  seleção, estruturação e validação do contexto fornecido a agentes.
- [Organização de
  software](/docs/arquitetura-engenharia/organizacao-software/): modelos para
  responsabilidades, dependências e fronteiras.
- [Spec-Driven Development
  estratégico](/docs/metodologia/sdd/sdd-Spec-Driven-Development-estrategia.html):
  especificações, rastreabilidade e evolução tecnológica com critérios de
  validação.
