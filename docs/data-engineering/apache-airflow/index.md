# Apache Airflow

Guias para projetar, operar e recuperar workflows no Apache Airflow.

Salvo quando a página declarar outra versão, exemplos novos desta seção usam a
interface pública do Airflow 3. Providers são versionados separadamente; confirme
compatibilidade, imports e parâmetros na versão instalada antes de levar um
snippet para produção.

Use os documentos conforme a decisão necessária:

- **autoria:** Operators, Hooks, Assets, idempotência e atomicidade;
- **capacidade:** sensores, XCom, executor e componentes da implantação;
- **operação:** backfill, timeouts, logs, backup e restauração;
- **desenvolvimento:** Dev Containers e validação local de DAGs.

Os exemplos mostram mecanismos e critérios. Eles não substituem testes com as
fontes, destinos, credenciais, volumes e objetivos operacionais do ambiente.
